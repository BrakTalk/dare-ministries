# HEIC fixture provenance

These are small, non-ministry test assets. The one public demo photograph is permissively licensed and contains no clear face; every other accepted-image fixture is synthetic.

The synthetic files were created from generated PPM/Y4M pixels in disposable Linux containers. libheif's `heif-enc` and x265 were used only to create test inputs; the deployed decoder does not contain x265 or any encoding path. Corrupt, truncated, MIME-spoofed, and oversized-dimension inputs are derived in memory by the tests instead of being committed as additional binaries.
